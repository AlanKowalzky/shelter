Task Description
This is the third and final part. See the main task description for the full project overview.

Add interactivity using pure JavaScript (no frameworks or libraries) to the pages built in Part 1 and Part 2:

A working burger menu (mobile/tablet)
An infinite carousel slider in the Our Friends block on Main
Pagination in the Our Friends block on Pets
A popup with pet details when a pet card is clicked (both pages)
Pet data must be stored in pets.json (already provided in the task folder - 8 pets total). Both the slider and the pagination use this data.

Requirements
Burger menu
On viewport widths below 768px, clicking the burger icon opens the navigation menu.
The menu opens with a smooth animation and overlays the page content.
The burger icon transforms into a close icon while the menu is open.
The menu closes when the user clicks: the close icon, the area outside the menu (the overlay), or any navigation link.
While the menu is open, the page behind it does not scroll.
Infinite carousel slider on the Main page (in Our Friends)
The slider displays the number of cards that fits the current viewport: 3 cards on desktop (1280px), 2 on tablet (768px), 1 on mobile (320px).
The slider has left/right arrow controls.
On each switch, the next group of cards is built from the 8 pets in pets.json with these constraints:
No pet from the currently visible group appears in the next group.
Within the next group, all displayed pets are unique.
The card order in the next group is random within the rules above.
Switching cards is animated (slide).
While the animation is running, repeated arrow clicks are ignored - animation triggers do not stack.
Pagination on the Pets page (in Our Friends)
The block displays a fixed list of 48 pet cards (6 pages × 8 cards on desktop, 8 pages × 6 cards on tablet, 16 pages × 3 cards on mobile).
The 48 cards are generated by repeating the 8 pets from pets.json such that:
All pets appear an equal number of times.
No two adjacent cards (in linear order) show the same pet.
The card order is the same on every page load (it's not regenerated between visits within the same session is not required - a stable order per load is enough).
Pagination controls: first page, previous page, current page indicator, next page, last page.
Disabled controls (e.g. "previous" on page 1) are visually inactive and don't react to clicks.
Switching pages is animated.
Popup (pet card details)
Clicking a pet card on either page opens a popup with that pet's details (name, type, breed, description, age, inoculations, diseases, parasites).
Pet data is taken from pets.json.
The popup overlays the page with a darkened backdrop.
The popup closes when the user clicks: the close button, or the backdrop outside the popup.
While the popup is open, the page behind it does not scroll.
The popup is responsive and matches the design at 1280px, 768px, and 320px.
