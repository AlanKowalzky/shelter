## Task 3: Shelter Part 3 - JavaScript Functionality

This PR implements the final part of the Shelter project, adding interactive features using pure JavaScript.

### Features implemented:
*   **Burger Menu:** Responsive mobile menu with smooth animations and overlay logic.
*   **Infinite Carousel:** Interactive slider in the "Our Friends" block on the Main page, ensuring unique pet cards and valid card transitions.
*   **Pagination:** 48-card pagination system on the Pets page with dynamic generation and animation.
*   **Popup:** Modal dialog for pet details, triggered by clicking cards, with backdrop support and body scroll locking.
*   **Data Handling:** Pet information is dynamically loaded from `pets.json`.

### Compliance:
*   Pure JavaScript (no frameworks/libraries).
*   Responsive design for 1280px, 768px, and 320px viewports.
*   Animations implemented using CSS transitions/animations.
